# i18n: typed catalog and ICU messages

## Decision

The UI languages are German (primary) and English. The rule covers
everything user-visible in the app and every server error that a human
reads.

- **A typed TS catalog** in `app/src/i18n/`: the German catalog defines the
  key set, every other language is a total record over it. A missing or
  extra key is a type error; there is no extraction tool and no runtime
  fallback to another language.
- **ICU MessageFormat via `intl-messageformat`**: plurals and interpolation
  live in the sentence, where translators see them. Dates, times and plural
  rules come from the built-in `Intl`.
- **Sentences are never glued together.** A value with markup inside a
  sentence is formatted as parts of one message. Helpers outside components
  receive the translator as an argument and never decide the language.
- **The language is an instance setting on the server,** not in the browser.
  Without a stored value the app follows the browser language and writes
  nothing. The first paint waits for the setting, and the document language
  follows it. The setting lives on the installation's settings page.
- **The server is language-free.** An error a human reads carries a stable
  code plus the parameters its sentence needs; an English technical text
  stands beside it for tools and logs. The app builds the sentence from the
  catalog and degrades to the English text, then to a generic sentence.
  Codes are append-only: a code keeps its meaning and parameters. CLI and log
  output is English.
- **A lint rule forbids literal copy in JSX** and runs as a CI gate; its
  allow list holds only non-copy (separators, key names, syntax markers).

## Why

- Not `i18next`: it brings a resource, namespace and backend model for
  problems a single-user tool with two languages does not have, keeps plurals
  in key suffixes instead of the sentence, and needs generated types for type
  safety. `intl-messageformat` is a small pure formatter; catalog and loading
  stay in our hands.
- Nothing is downloaded at runtime; a self-hosted tool must work offline.
- Without a gated first paint, an instance set to one language would flash
  the other; a wrong document language breaks screen readers and hyphenation.
- An instance-wide setting does not belong in the campaign switcher.

## Consequences

- Every new error code needs a catalog entry in both languages.
- The repository language is a separate decision (`decisions/language`).
